# HagaHelwa - Ecommerce Website

This project is an e-commerce website built with PHP, HTML, CSS, and JavaScript. It includes pages for the shop, shopping cart, login, signup, and administration.

## Description

HagaHelwa is an online shopping website with an attractive user interface and main sections such as:
- Home page
- Shop page
- Product page
- Shopping cart page
- Blog page
- About page
- Contact page
- Login and signup pages
- Additional admin panel

## Features

- Modern and user-friendly store interface
- Multiple pages for products and services
- Shopping cart and order support
- Responsive design for different screen sizes
- Ready-to-use admin template

## Requirements

To run the project, you need:
- XAMPP or WAMP
- PHP
- Apache
- A web browser

## How to Run

1. Copy the project folder into the htdocs folder inside XAMPP
   - Example: `C:\xampp\htdocs\Rout\HagaHelwawithoutDB`
2. Start Apache from the XAMPP control panel
3. Open your browser and visit:
   - `http://localhost/Rout/HagaHelwawithoutDB/`
4. To access the admin panel:
   - `http://localhost/Rout/HagaHelwawithoutDB/admin/`

## Project Structure

- `index.php` — Home page
- `shop.php` — Shop page
- `product.php` — Product page
- `cart.php` — Shopping cart
- `login.php` / `signup.php` — Login and signup
- `contact.php` / `about.php` / `blog.php` — Additional pages
- `admin/` — Admin panel files
- `inc/` — Shared header and footer files
- `handle/` — Request and registration handling files
- `css/`, `js/`, `img/` — Styling and image assets

## Notes

This project provides a complete store interface and a set of PHP files ready for development and customization. If you want to use the full dynamic features (such as storage and orders), you may need to connect it to a MySQL database and add the appropriate connection logic in the handling files.
